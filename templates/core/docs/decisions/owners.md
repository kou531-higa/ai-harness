# 決定者マップ

判断の種類ごとに、誰が決めるかと期限の目安。`/decision-memo` と未決事項台帳が読む。
仕様の frontmatter に `owner` があれば、そちらを優先する。

**入れたら、表の決定者（`@customer` などの役の名前）を、本物のチームの名前に置き換える。** 役の名前は、GitHub の本物のアカウントと同じことがある。置き換えるまでは、チケットに書くときに書式つき（`` `@customer` ``）にしてメンションにしない。

| 判断の種類 | 決定者 | 期限 |
|---|---|---|
| 仕様の未確定 | @customer | 2営業日 |
| 仕様の食い違い | @pm | 2営業日 |
| 業務の扱い・顧客との約束 | @customer | 2営業日 |
| 技術の選択・共通部品 | @tech-lead | 1営業日 |
| セキュリティ・個人情報 | @tech-lead | 1営業日 |
| 戻せない操作 | @pm | その都度 |
