# 決まりの一覧

人が一度決めた判断の基準を、次から AI が自分で使えるようにしたもの。`/harness-rule` で足し、人が PR で採用する。

- ここの決まりで答えが出る論点は、人へ戻さずに決まりに従う。PR と仕様に、従った決まりの ID を書く（例：`R-001 による`）
- 当てはまるか迷うとき、決まりどうしが食い違うとき、決まりの「当てはまらない場合」に入るときは、従わずに人へ戻す
- 決まりを AI が足したり変えたりしない（足すのは `/harness-rule` の PR を人が採用したときだけ）

| ID | 決まり | 当てはまらない場合（人へ戻す） | 元の決定 | 効く場所 |
|---|---|---|---|---|
