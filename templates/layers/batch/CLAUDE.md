# batch/ の規約（バッチ：Python 3.12・click・psycopg2）

このディレクトリのファイルを触るときに読み込まれる。全体の規約はリポジトリ直下の CLAUDE.md。

## 書き方
- 1つのバッチは1つの click のコマンド（`commands/`）。DB の接続・トランザクション・ログは共通の `core/` を使う
- SQL は jinja2 のテンプレート（`sql/`）に置き、値はプレースホルダで渡す。文字列をつないで SQL を作らない
- 取り込むファイルの1行は pydantic のモデルで検査する。検査に落ちた行は、エラー行として記録して止めずに続ける
- **再実行しても結果が変わらない**ように作る（同じファイルを2回取り込んでも、二重に登録しない）
- 取引先ごとの違いは、変換の定義（設定や変換表）で吸収する。取引先ごとの if 文を足さない
- 重い集計や締めの処理は、DB のプロシージャ（`db/procedures/`）を呼ぶ。判定を Python 側で別に書かない
- ログに個人情報（氏名・電話番号・住所・メール）を出さない。件数と ID だけを出す

## テスト
- 単体テストは pytest。DB を使うテストは testcontainers（PostgreSQL）で `tests/integration/` に置く
- プロシージャのテストは `tests/sp_integration/`。重いテストは `pytest-xdist` で並列に回す

## 止まって人へ戻す

- 本番のデータの補正が必要 → `ai-stop:irreversible`
