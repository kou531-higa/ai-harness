# db/ の規約（マイグレーションとプロシージャ：PostgreSQL・PL/pgSQL）

このディレクトリのファイルを触るときに読み込まれる。全体の規約はリポジトリ直下の CLAUDE.md。

## 書き方
- マイグレーションは前に進めるだけ。**適用済みのマイグレーションは編集しない**（フックが止める）。直すときは新しいマイグレーションを足す
- 列の削除や型の変更は、2回に分ける（新しい列を足して移す → 次のリリースで古い列を消す）
- データの補正をマイグレーションに入れない（別の手順で、人の承認を通す）
- プロシージャは `procedures/` に1ファイル1つ。`CREATE OR REPLACE` で書き、Git で変更を追える形にする
- 状態の判定はカタログから作った関数（`fn_status_*`）を呼ぶ。状態の値を直接書かない
- 1つのプロシージャが長くなりすぎたら（目安200行）、分けることを提案する

## テスト
- プロシージャのテストは、testcontainers の PostgreSQL で実行する（`batch/tests/sp_integration/`）

## 止まって人へ戻す
- 表の構造を変える（マイグレーション）・プロシージャの結果が変わる → 計画を示して人の OK を待つ
- 本番のデータに影響する → `ai-stop:irreversible`
